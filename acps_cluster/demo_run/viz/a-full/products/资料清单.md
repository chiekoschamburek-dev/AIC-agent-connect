[1/5] 相关性：★★★☆（GAT/子图注意力；非引文网络）
标题：Robust Hierarchical Graph Classification with Subgraph Attention
作者：Sambaran Bandyopadhyay; Manasvi Aggarwal; M. Narasimha Murty
年份：2020
arXiv ID：2007.10908v1
链接：https://arxiv.org/pdf/2007.10908v1 （摘要页 https://arxiv.org/abs/2007.10908）
摘要：图神经网络在图表示与分类任务中受到广泛关注，将注意力机制施加在节点邻域上可提升性能并识别更关键的邻居节点；但现实场景中往往是某个节点子集整体而非单个节点对决定标签。作者据此提出「子图注意力」概念，并结合层次化图池化，提出子图注意力池化网络 SubGattPool，联合学习子图注意力与两种层次注意力机制（层内节点重要性、层间层级重要性），以应对真实图噪声化的层次结构。在多个公开图分类数据集上达到或持平 SOTA，并在合成与真实图数据集上验证了各组件的有效性。

[2/5] 相关性：★★☆☆（语义图注意力网络；应用于 LiDAR 回环检测）
标题：PNE-SGAN: Probabilistic NDT-Enhanced Semantic Graph Attention Network for LiDAR Loop Closure Detection
作者：Xiong Li; Shulei Liu; Xingning Chen; Yisong Wu; Dong Zhu
年份：2025
arXiv ID：2504.08280v2
链接：https://arxiv.org/pdf/2504.08280v2 （摘要页 https://arxiv.org/abs/2504.08280）
摘要：LiDAR 回环检测对 SLAM 的一致性至关重要，但现有语义图方法存在几何表示粗糙、对噪声与视角变化缺乏时间鲁棒性的问题。作者提出 PNE-SGAN，以正态分布变换（NDT）协方差矩阵作为判别性节点特征增强语义图并送入 GAT 处理，同时将图相似度分数整合进概率化时间滤波框架（HMM/贝叶斯滤波），计入不确定里程计并采用前后向平滑处理歧义。在 KITTI 序列 00 与 08 上分别取得 96.2% 与 95.1% 的平均精度，在困难的双向回环场景中显著优于既有方法。

标题：Graph Pattern Loss based Diversified Attention Network for Cross-Modal Retrieval
作者：Xueying Chen; Rong Zhang; Yibing Zhan
年份：2021
arXiv ID：2106.13552v1
链接：https://arxiv.org/pdf/2106.13552v1 （摘要页 https://arxiv.org/abs/2106.13552）
摘要：面向无监督跨模态检索，提出图模式损失的多样化注意力网络 GPLDAN：通过多样化注意力特征投影器建模不同表示间的交互以生成同一实例的多种表示；设计考虑所有表示间距离的图模式损失挖掘表示相关性；并引入模态分类器显式判别特征所属模态以增强判别力。在四个公开数据集上验证了竞争力。
