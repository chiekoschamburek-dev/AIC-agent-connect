## 一、近一年 + 主题相关（唯一命中，优先使用）

### 1. PNE-SGAN: Probabilistic NDT-Enhanced Semantic Graph Attention Network for LiDAR Loop Closure Detection
- **arXiv ID**：2504.08280v2
- **年份**：2025
- **作者**：Xiong Li, Shulei Liu, Xingning Chen, Yisong Wu, Dong Zhu
- **链接**：https://arxiv.org/pdf/2504.08280v2
- **要点**：将 NDT 协方差矩阵作为语义图的判别性节点特征送入 GAT，再把图相似度接入 HMM/Bayes 时序滤波框架，用前后向平滑处理回环歧义；在 KITTI 00/08 序列上取得 96.2% / 95.1% AP，双向回环场景下显著优于既有方法。
- **相关度**：高——明确以 GAT 为核心组件。
- **备注**：应用型工作（GNN + SLAM 回环检测），偏工程，不是 GAT 方法论本身的改进。

## 二、主题相关但不满足「近一年」

### 2. Visual Attention Network
- **arXiv ID**：2202.09741v5 ｜ **年份**：2022
- **作者**：Meng-Hao Guo, Cheng-Ze Lu, Zheng-Ning Liu, Ming-Ming Cheng, Shi-Min Hu
- **链接**：https://arxiv.org/pdf/2202.09741v5
- **要点**：提出大核注意力（LKA）线性注意力并构建 VAN，在分类/检测/分割/全景/姿态多项任务上超越同规模 ViT 与 CNN（ImageNet 87.8%，ADE20K 分割 50.1 mIoU）。
- **相关度**：**低**。计算机视觉自注意力，与图注意力网络（GAT）只是名词撞车，不建议纳入 GAT 综述。

### 3. Robust Hierarchical Graph Classification with Subgraph Attention
- **arXiv ID**：2007.10908v1 ｜ **年份**：2020
- **作者**：Sambaran Bandyopadhyay, Manasvi Aggarwal, M. Narasimha Murty
- **链接**：https://arxiv.org/pdf/2007.10908v1
- **要点**：提出 SubGattPool，联合学习「子图注意力」与两层层次注意力（层内节点重要性 + 层间重要性）完成图分类，在多个公开数据集上达到 SOTA 或保持竞争力。
- **相关度**：中高——图上的注意力建模方法，但属 2020 年工作。

### 4. Graph Pattern Loss based Diversified Attention Network for Cross-Modal Retrieval
- **arXiv ID**：2106.13552v1 ｜ **年份**：2021
- **作者**：Xueying Chen, Rong Zhang, Yibing Zhan
- **链接**：https://arxiv.org/pdf/2106.13552v1
- **要点**：面向无监督跨模态检索，设计多样化注意力特征投影器 + 图模式损失（图上枚举表征两两距离），并加模态分类器引导融合，在 4 个公开数据集上优于当时 SOTA。
- **相关度**：中——是「graph + attention」的跨模态检索工作，与图神经网络 GAT 不同源。
